# Странники галактики

Космическая игра на Godot 4: галактика и полёты как в «Космических рейнджерах», бой из кабины как в «Паркане», высадки на планеты как в No Man's Sky.

Дизайн-документ: https://claude.ai/artifact/D6QkEtuT77614uiXz29YYv

## Как открыть

1. Запустите Godot 4 (последняя стабильная 4.x, обычная версия, не .NET).
2. В менеджере проектов нажмите «Импорт» и выберите файл `project.godot` в корне этой папки.
3. Нажмите F5, чтобы запустить игру.

## Что уже есть

- `scenes/system/star_system.tscn` — звёздная система, вид сверху. Клик по планете, станции или пустому месту задаёт курс, колесо мыши меняет масштаб.
- `scripts/core/game_state.gd` — глобальное состояние (автозагрузка `GameState`): время галактики идёт всегда, 1 секунда = 1 час; деньги в валюте «ПОТОМ».
- `prototype/stranniki.html` — браузерный прототип всей петли игры (карта, станции, экипаж, бой, планеты). Открывается в любом браузере.

## Структура

```
scenes/   сцены Godot
scripts/  код на GDScript
prototype/ браузерный прототип
```
